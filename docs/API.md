# API contract

The exact MoonBit signatures will be generated from compiling packages. The
stable conceptual operations for v0.1 are:

- parse text into an ordered document and diagnostics;
- compile a glob and match normalized relative paths;
- validate standard property values;
- resolve a target against an injectable configuration source;
- explain every assignment, override, and unset operation;
- serialize reports to deterministic JSON.

This document will be updated with checked signatures before v0.1.0.
